# 수북 (SUBOOK)

영어 지문을 넣으면 수업에 바로 쓸 수 있는 **A4 부교재**를 만들어 주는 도구입니다.
현직 영어 교사가 쓰려고 만들었고, **모든 선생님께 무료로 열려 있습니다.**

👉 **[바로 사용하기](https://kkhland.github.io/subook/)**

---

## 무엇을 만들어 주나요

영어 지문 하나를 넣으면 A4 여러 장으로 된 학습자료가 나옵니다.

| 항목 | 내용 |
|---|---|
| 지문 해석 | 문장마다 번호를 붙여 영문과 우리말 해석을 나란히 배치 |
| 핵심 가이드 | 제목·주제·요약·전개 구조표·출제 포인트·Teacher's Insight |
| 한 문장 읽기 | 문장별 해석 → 한 줄 요약 → 쉬운 예시 |
| 정밀 판독 | 6개 관점(정보 확인·핵심 원리·함정 주의·인과 관계·지칭 추론·요지 파악) 질문과 해설 |
| 단어 리스트 | 품사·의미·유의어·반의어 표 |
| 뜻쓰기 / 스펠링 테스트 | 2단 배치, 학생이 쓸 공간을 지면에 맞춰 확보 |

필요한 항목만 골라 만들 수 있고, 다 만든 뒤에도 **항목별·쪽별로 인쇄에서 빼는** 게 가능합니다.
한 번 만들어서 문제지와 해설지를 따로 뽑을 때 씁니다.

입력은 **PDF · DOCX · HWPX · TXT** 파일이나 직접 붙여넣기를 지원합니다.
PDF 는 쪽 미리보기를 보고 분석할 쪽만 고를 수 있습니다.

## 어떻게 무료인가요

수북에는 **서버가 없습니다.** 브라우저 안에서만 돌아갑니다.

- 선생님이 **구글 AI Studio 무료 API 키**를 발급받아 넣으면, 그 키로 동작합니다
- 키는 선생님 브라우저에만 저장되고, 어디로도 전송되지 않습니다
- 올린 파일과 지문도 마찬가지입니다 — AI 분석을 요청할 때만 구글로 갑니다
- 계정도, 결제도, 사용량 제한도 없습니다

그래서 아무에게도 비용이 발생하지 않고, 앞으로도 무료로 유지됩니다.

### API 키 발급 (한 번만 하면 됩니다)

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 접속 → 구글 계정 로그인
2. **Create API key** 클릭
3. `AIzaSy…` 로 시작하는 키를 복사
4. 수북 오른쪽 위 **「AI 연결」** 에 붙여넣기

카드 등록은 필요 없습니다.

## 쓰는 방법 두 가지

**웹에서 바로 쓰기** — 위의 [바로 사용하기](https://kkhland.github.io/subook/) 링크를 열면 됩니다.

**파일로 받아서 쓰기** — 학교망에서 막히거나 인터넷이 불안정할 때. 위 링크에서 브라우저의
«다른 이름으로 저장»(Ctrl+S) 을 하면 `index.html` 파일 하나가 저장되고, 그 파일을
더블클릭하면 인터넷 없이도 똑같이 동작합니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5233)
npm run check    # 타입 검사
npm run build    # dist/index.html 단일 파일 생성
```

Vite + React + TypeScript + Tailwind CSS. 빌드하면 모든 JS·CSS·PDF 처리 엔진이
`dist/index.html` 한 파일 안에 들어갑니다.

```
src/
  ai/        생성 엔진 — 항목별 지시문, JSON 스키마, 호출 관리
  lib/       자료 종류 정의, 지문·문장 분리, 파일 텍스트 추출
  print/     A4 조판 — 미리보기와 인쇄가 같은 화면을 씁니다
  components/ 4단계 위저드 화면
```
